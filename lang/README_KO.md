## 💡 이게 뭔가요?

### PS HELP는 PowerShell 명령을 목록과 버튼이 있는 평범한 창으로 바꿔 줍니다.

명령을 외울 필요도, 검은 콘솔에 입력할 필요도 없습니다. 왼쪽에서 섹션을 클릭하고, 목록에서 항목을 클릭하고, 동작 버튼을 클릭하면 됩니다. 모든 버튼은 **실제 PowerShell 명령**을 실행하고, 프로그램은 아래쪽에 어떤 명령인지 항상 보여 주므로 쓰면서 PowerShell을 배우게 됩니다.

모든 일이 한 창에서 일어납니다. 팝업 창도, 뒤에서 돌아가는 검은 콘솔도 없습니다. 프로그램은 인터넷으로 아무것도 보내지 않고, 설정은 사용자 컴퓨터에 남습니다.

## 🚀 빠른 시작

**1.** [Releases](https://github.com/MRGREGOR85/PS-HELP-/releases/latest)에서 패키지를 **다운로드**하고 원하는 곳, 예를 들어 바탕 화면에 압축을 풉니다.  
**2.** `PS HELP.exe`를 두 번 클릭해 **실행**합니다. 검은 콘솔은 나타나지 않습니다. 첫 실행 때 Windows가 SmartScreen으로 경고할 수 있습니다: **추가 정보 → 실행**.  
**3.** 왼쪽에서 **섹션을 고릅니다**. 메뉴에는 열 개의 섹션이 있고 아래에 **설정**이 있습니다.  
**4.** 목록에서 **항목을 클릭**합니다. 오른쪽에 세부 정보와 동작 버튼이 나타나고, **POWERSHELL 명령** 상자에 그 버튼이 실행할 명령이 보입니다.  
**5.** **변경을 승인합니다.** 무언가를 바꾸는 동작은 모두 전체 명령을 보여 주고 **예** 또는 **아니요**를 기다립니다.  
**6.** **F6을 누르면** 명령 모드가 됩니다. PowerShell 명령 타일, 예시 값이 들어 있는 입력란, **실행**, **복사**, **문서**, 그리고 아래쪽의 결과 콘솔이 나타납니다.  
**7.** **언어와 테마**는 **설정**에서 고릅니다. 자동으로 저장되어 다음 실행 때도 그대로입니다.  

**필요한 것:** Windows 10 또는 11 · Windows PowerShell 5.1 (모든 Windows 10/11에 들어 있습니다) · 관리자 권한은 일부 변경에만 필요합니다: 서비스, 표준 시간대, 날짜, 스크립트 정책.

| 패키지 안의 파일 | 용도 |
|---|---|
| `PS HELP.exe` | 프로그램 전체가 한 파일에 – PS HELP를 실행합니다. USB 메모리에서도 작동합니다 |
| `PS_HELP.ico` | 프로그램 아이콘 |
| `LICENSE` | 프로그램 라이선스 |

> 💡 프로그램 파일은 숨김 폴더 `app`에 저절로 풀립니다. 그 안을 들여다보거나 무언가를 바꿀 필요는 없습니다.

## ✨ 기능

| 기능 | 의미 |
|---|---|
| **10개 섹션** | 프로세스, 서비스, 파일과 폴더, ZIP 압축, 네트워크, 컴퓨터, 날짜와 시간, 클립보드, 이벤트 로그, 보안 |
| **두 가지 모드 (F6)** | 버튼이 준비된 표, 또는 PowerShell 명령 타일 |
| **40개가 넘는 명령** | 각각 설명, 예시 값, 마이크로소프트 문서 링크 포함 |
| **명령 미리 보기** | 버튼이 실행할 명령이 항상 아래쪽에 보입니다 |
| **예 / 아니요 확인** | 무언가를 바꾸는 동작은 먼저 묻고 전체 명령을 보여 줍니다 |
| **24가지 테마** | 어두운 Graphite부터 Hacker Green, 밝은 Snow White까지 |
| **32개 언어** | 화면 전체가 바로 바뀌고 명령은 그대로입니다 |
| **설치 없음** | 기본 제공되는 Windows PowerShell 5.1에서 작동하고 따로 설치할 것이 없습니다 |
| **창 하나** | 팝업 창도, 뒤에서 돌아가는 검은 콘솔도 없습니다 |
| **진행률이 보이는 다운로드** | 진행 바, 퍼센트, 속도, 남은 시간. 중간에 멈출 수 있습니다 |
| **비공개** | 인터넷으로 아무것도 보내지 않고, 설정은 사용자 컴퓨터에 남습니다 |

## 🧭 모든 섹션

### ⚙️ 프로세스

지금 실행 중인 프로그램 목록입니다. 이름, PID, 바가 있는 CPU, 메모리. 2초마다 저절로 새로 고쳐집니다. 검색, **새로 고침**, **프로그램 실행**. 프로그램을 클릭하면 CPU, 메모리, 시작 시각, 스레드와 함께 **프로그램 종료**, **프로그램 폴더 열기**, **세부 정보** 버튼이 나타납니다.

F6 명령: `Get-Process`, `Stop-Process`, `Start-Process`, `Wait-Process`

### 🔧 서비스

Windows 서비스를 상태(실행 중 또는 중지)와 시작 유형과 함께 보여 줍니다. 동작: **시작**, **중지**, **다시 시작**, **자동 시작**, **수동 시작**, **서비스 사용 안 함**. 예: 멈춘 프린터는 *Print Spooler* 서비스입니다 → **다시 시작**.

F6 명령: `Get-Service`, `Start-Service`, `Stop-Service`, `Restart-Service`, `Set-Service`

### 📁 파일과 폴더

작은 탐색기입니다. **폴더** 입력란, **위로**, **새 폴더**, **휴지통 비우기**. 파일에는 **열기**, **복사할 위치…**, **이동할 위치…**, **이름 바꾸기**, **삭제**(휴지통이 아니라 완전히), **SHA256 체크섬**, 인터넷에서 받은 파일의 **차단 해제**.

F6 명령: `Get-ChildItem`, `Copy-Item`, `Move-Item`, `Rename-Item`, `Remove-Item`, `New-Item`, `Test-Path`, `Invoke-Item`, `Get-FileHash`, `Unblock-File`, `Clear-RecycleBin`

### 🗜️ ZIP 압축

파일이나 폴더를 고르고 **ZIP으로 압축**을 클릭합니다. `.zip` 파일을 고르고 **ZIP 풀기**를 클릭하면 같은 이름의 폴더로 풀립니다. 큰 압축 파일은 백그라운드에서 처리되어 창이 멈추지 않습니다.

F6 명령: `Compress-Archive`, `Expand-Archive`

### 🌐 네트워크

**연결 확인**은 응답 시간과 상태가 함께 나오는 ping을 4번 보냅니다. **파일 다운로드**는 **Ctrl+V**로 붙여 넣은 링크를 받습니다. 아래쪽에 진행 바, 퍼센트, 속도, 남은 시간이 보이고 **다운로드 중단** 버튼으로 언제든 멈출 수 있습니다. 명령 모드에서는 `OutFile` 란에 기존 폴더 안 파일의 전체 경로를 적습니다. 예: `C:\Temp\file.zip`.

F6 명령: `Test-Connection`, `Invoke-WebRequest`

### 🖥️ 컴퓨터

컴퓨터 이름, Windows 버전, CPU, 코어 수, 전체와 남은 메모리, 그래픽 카드, 디스크 여유 공간, 가동 시간, 마지막 시작, 업데이트 개수. 모든 값을 클립보드로 복사할 수 있습니다. 버튼: **업데이트 목록**, **컴퓨터 이름 바꾸기**, **다시 시작**, **컴퓨터 끄기**.

F6 명령: `Get-ComputerInfo`, `Get-CimInstance`, `Get-HotFix`, `Get-Uptime`, `Get-PSDrive`, `Rename-Computer`, `Restart-Computer`, `Stop-Computer`

### 🕒 날짜와 시간

현재 날짜, 시간, 표준 시간대와 검색이 되는 전체 시간대 목록입니다. **이 시간대로 설정**과 **날짜와 시간 설정**은 관리자 권한이 필요합니다.

F6 명령: `Get-Date`, `Set-Date`, `Get-TimeZone`, `Set-TimeZone`

### 📋 클립보드

지금 클립보드에 있는 내용을 한 줄씩 보여 줍니다. **이 줄 복사**, 또는 텍스트를 입력하고 **클립보드에 넣기**를 클릭합니다.

F6 명령: `Get-Clipboard`, `Set-Clipboard`

### 📜 이벤트 로그

시스템과 응용 프로그램 로그에서 최근 오류와 경고 200건입니다. 시각, 수준, 원본, 설명. **전체 설명**으로 이벤트 전문을 볼 수 있습니다.

F6 명령: `Get-WinEvent`, `Get-Counter`

### 🔒 보안

범위별 PowerShell 스크립트 실행 정책입니다. 사용자 범위에는 **스크립트 허용 (RemoteSigned)**, **스크립트 차단 (Restricted)**, **설정 지우기 (Undefined)**. **파일에 접근할 수 있는 대상**은 권한을 읽기 전용으로 보여 줍니다.

F6 명령: `Get-ExecutionPolicy`, `Set-ExecutionPolicy`, `Get-Acl`

## 🎨 테마

**설정 → 테마**. 이름을 클릭하면 색이 바로 바뀝니다. 목록 위에 검색란이 있습니다. 예: `blue`. 24가지 모두 프로그램에 들어 있고, 고른 테마는 자동으로 저장됩니다.

## 🌍 언어

**설정 → 언어**. 화면 전체가 바로 바뀌고 PowerShell 명령은 그대로입니다. 지원 언어: 폴란드어, 영어, 독일어, 체코어, 슬로바키아어, 우크라이나어, 러시아어, 리투아니아어, 라트비아어, 에스토니아어, 스페인어, 프랑스어, 이탈리아어, 포르투갈어, 네덜란드어, 스웨덴어, 덴마크어, 노르웨이어, 핀란드어, 헝가리어, 루마니아어, 불가리아어, 그리스어, 크로아티아어, 세르비아어, 슬로베니아어, 튀르키예어, 베트남어, 인도네시아어, 일본어, 한국어, 중국어.

## 🆘 뭔가 안 되나요?

| 증상 | 해결 |
|---|---|
| 창이 열리지 않습니다 | `%APPDATA%\PS HELP\startup-error.log` 파일을 확인하세요 |
| 「권한이 없습니다」 | 그 변경에는 관리자 권한이 필요합니다 |
| 명령이 오래 걸립니다 | 아래쪽 콘솔에서 **명령 중단**을 클릭하세요 |
| 설정을 처음부터 다시 하고 싶습니다 | `%APPDATA%\PS HELP\settings.json` 파일을 삭제하세요 |
| 백신이나 SmartScreen이 `PS HELP.exe`를 경고합니다 | 이 파일에는 유료 디지털 서명이 없고, 프로그램 코드 전체가 `app` 폴더에 공개되어 있습니다 |

## 🔒 안전한가요?

### PS HELP는 Windows PowerShell의 기본 명령만 사용합니다.

ping이나 파일 다운로드처럼 사용자가 직접 요청한 것 외에는 인터넷으로 데이터를 보내지 않습니다. 변경할 때마다 전체 명령을 보여 주고 **예**를 기다립니다. 프로그램 코드 전체가 `app` 폴더에 공개되어 있어 직접 읽을 수 있습니다.
