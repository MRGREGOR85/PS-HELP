## 💡 これは何？

### PS HELP は PowerShell のコマンドを、一覧とボタンのある普通のウィンドウに変えます。

コマンドを覚える必要も、黒いコンソールに打ち込む必要もありません。左のセクションをクリックし、一覧の項目をクリックし、操作ボタンをクリックするだけです。どのボタンも**本物の PowerShell コマンド**を実行し、プログラムは下部にどのコマンドかを必ず表示するので、使いながら PowerShell を覚えられます。

すべてが 1 つのウィンドウで完結します。ポップアップも、背後の黒いコンソールもありません。プログラムはインターネットへ何も送信せず、設定はお使いのパソコンに残ります。

## 🚀 クイックスタート

**1.** [Releases](https://github.com/MRGREGOR85/PS-HELP-/releases/latest) からパッケージを**ダウンロード**し、好きな場所、たとえばデスクトップに展開します。  
**2.** `PS HELP.exe` をダブルクリックで**起動**します。黒いコンソールは表示されません。初回起動時に Windows が SmartScreen で警告することがあります。**詳細情報 → 実行** を選んでください。  
**3.** 左で**セクションを選びます**。メニューには 10 のセクションがあり、下に**設定**があります。  
**4.** 一覧の**項目をクリック**します。右に詳細と操作ボタンが現れ、**POWERSHELL コマンド**の枠にそのボタンが実行するコマンドが表示されます。  
**5.** **変更を承認します。** 何かを変更する操作はすべて、完全なコマンドを表示して **はい** か **いいえ** を待ちます。  
**6.** **F6 を押す**とコマンドモードになります。PowerShell コマンドのタイル、サンプル値が入った入力欄、**実行**、**コピー**、**ドキュメント**、そして下部に結果のコンソールが表示されます。  
**7.** **言語とテーマ**は**設定**で選びます。自動で保存され、次回の起動時にもそのままです。  

**必要なもの:** Windows 10 または 11 · Windows PowerShell 5.1（Windows 10/11 には標準で入っています）· 管理者権限は一部の変更のみ（サービス、タイムゾーン、日付、スクリプトポリシー）。

| パッケージ内のファイル | 役割 |
|---|---|
| `PS HELP.exe` | プログラム全体が 1 ファイルに。PS HELP を起動します。USB メモリからでも動きます |
| `PS_HELP.ico` | プログラムのアイコン |
| `LICENSE` | プログラムのライセンス |

> 💡 プログラムのファイルは隠しフォルダー `app` に自動で展開されます。中を見る必要も、変更する必要もありません。

## ✨ 機能

| 機能 | 内容 |
|---|---|
| **10 のセクション** | プロセス、サービス、ファイルとフォルダー、ZIP アーカイブ、ネットワーク、コンピューター、日付と時刻、クリップボード、イベントログ、セキュリティ |
| **2 つのモード (F6)** | ボタンがそろった表、または PowerShell コマンドのタイル |
| **40 以上のコマンド** | それぞれに説明、サンプル値、マイクロソフトのドキュメントへのリンク |
| **コマンドのプレビュー** | ボタンが実行するコマンドが常に下部に表示されます |
| **はい / いいえ の確認** | 何かを変更する操作は必ず先に確認し、完全なコマンドを表示します |
| **24 種類のテーマ** | 暗い Graphite から Hacker Green、明るい Snow White まで |
| **32 の言語** | 画面全体がすぐ切り替わり、コマンドはそのままです |
| **インストール不要** | 標準搭載の Windows PowerShell 5.1 で動作し、追加で入れるものはありません |
| **ウィンドウは 1 つ** | ポップアップも、背後の黒いコンソールもありません |
| **進捗つきダウンロード** | バー、パーセント、速度、残り時間。途中で中止もできます |
| **プライベート** | インターネットへ何も送信せず、設定はお使いのパソコンに残ります |

## 🧭 すべてのセクション

### ⚙️ プロセス

いま動いているプログラムの一覧です。名前、PID、バー付きの CPU、メモリー。2 秒ごとに自動更新されます。検索、**更新**、**プログラムを起動**。プログラムをクリックすると CPU、メモリー、起動時刻、スレッドに加え、**プログラムを終了**、**プログラムのフォルダーを開く**、**詳細** のボタンが表示されます。

F6 のコマンド: `Get-Process`, `Stop-Process`, `Start-Process`, `Wait-Process`

### 🔧 サービス

Windows のサービスを状態（実行中または停止）とスタートアップの種類とともに表示します。操作: **開始**、**停止**、**再起動**、**自動で開始**、**手動で開始**、**サービスを無効化**。例: 固まったプリンターは *Print Spooler* サービスです → **再起動**。

F6 のコマンド: `Get-Service`, `Start-Service`, `Stop-Service`, `Restart-Service`, `Set-Service`

### 📁 ファイルとフォルダー

小さなエクスプローラーです。**フォルダー** 欄、**上へ**、**新しいフォルダー**、**ごみ箱を空にする**。ファイルには **開く**、**コピー先…**、**移動先…**、**名前の変更**、**削除**（ごみ箱ではなく完全に削除）、**SHA256 チェックサム**、インターネットから入手したファイルの **ブロックを解除**。

F6 のコマンド: `Get-ChildItem`, `Copy-Item`, `Move-Item`, `Rename-Item`, `Remove-Item`, `New-Item`, `Test-Path`, `Invoke-Item`, `Get-FileHash`, `Unblock-File`, `Clear-RecycleBin`

### 🗜️ ZIP アーカイブ

ファイルかフォルダーを選んで **ZIP に圧縮** をクリックします。`.zip` ファイルを選んで **ZIP を展開** をクリックすると、同じ名前のフォルダーに展開されます。大きなアーカイブはバックグラウンドで処理され、ウィンドウは固まりません。

F6 のコマンド: `Compress-Archive`, `Expand-Archive`

### 🌐 ネットワーク

**接続を確認** は応答時間と状態つきの ping を 4 回送ります。**ファイルをダウンロード** は **Ctrl+V** で貼り付けたリンクを受け取ります。下部に進捗バー、パーセント、速度、残り時間が表示され、**ダウンロードを中止** ボタンでいつでも止められます。コマンドモードでは `OutFile` 欄に既存フォルダー内のファイルの完全なパスを指定します（例: `C:\Temp\file.zip`）。

F6 のコマンド: `Test-Connection`, `Invoke-WebRequest`

### 🖥️ コンピューター

コンピューター名、Windows のバージョン、CPU、コア数、合計と空きのメモリー、グラフィックカード、ディスクの空き容量、稼働時間、最後の起動、更新の数。どの値もクリップボードにコピーできます。ボタン: **更新の一覧**、**コンピューター名を変更**、**再起動**、**シャットダウン**。

F6 のコマンド: `Get-ComputerInfo`, `Get-CimInstance`, `Get-HotFix`, `Get-Uptime`, `Get-PSDrive`, `Rename-Computer`, `Restart-Computer`, `Stop-Computer`

### 🕒 日付と時刻

現在の日付、時刻、タイムゾーンと、検索できる全タイムゾーンの一覧です。**このゾーンを設定** と **日付と時刻を設定** には管理者権限が必要です。

F6 のコマンド: `Get-Date`, `Set-Date`, `Get-TimeZone`, `Set-TimeZone`

### 📋 クリップボード

いまクリップボードにある内容を行ごとに表示します。**この行をコピー**、またはテキストを入力して **クリップボードに入れる** をクリックします。

F6 のコマンド: `Get-Clipboard`, `Set-Clipboard`

### 📜 イベントログ

システムとアプリケーションのログから直近 200 件のエラーと警告を表示します。時刻、レベル、ソース、説明。**完全な説明** でイベントの全文が見られます。

F6 のコマンド: `Get-WinEvent`, `Get-Counter`

### 🔒 セキュリティ

スコープごとの PowerShell スクリプト実行ポリシーです。ユーザースコープには **スクリプトを許可 (RemoteSigned)**、**スクリプトをブロック (Restricted)**、**設定をクリア (Undefined)**。**ファイルへのアクセス権** は権限を読み取り専用で表示します。

F6 のコマンド: `Get-ExecutionPolicy`, `Set-ExecutionPolicy`, `Get-Acl`

## 🎨 テーマ

**設定 → テーマ**。名前をクリックすると色がすぐ変わります。一覧の上に検索欄があります（例: `blue`）。24 種類すべてがプログラムに内蔵されており、選んだテーマは自動で保存されます。

Midnight · Graphite · Violet · Light · CMD HELP · Ghost Dark · Midnight Blue · Deep Ocean · Arctic Blue · Carbon Black · Silver Steel · Studio Light · Snow White · Emerald · Hacker Green · Forest · Neon Cyan · Cyber Purple · Royal Violet · Crimson · Ruby Red · Sunset Orange · Golden · Rose Pink

## 🌍 言語

**設定 → 言語**。画面全体がすぐ切り替わり、PowerShell のコマンドはそのままです。対応言語: ポーランド語、英語、ドイツ語、チェコ語、スロバキア語、ウクライナ語、ロシア語、リトアニア語、ラトビア語、エストニア語、スペイン語、フランス語、イタリア語、ポルトガル語、オランダ語、スウェーデン語、デンマーク語、ノルウェー語、フィンランド語、ハンガリー語、ルーマニア語、ブルガリア語、ギリシャ語、クロアチア語、セルビア語、スロベニア語、トルコ語、ベトナム語、インドネシア語、日本語、韓国語、中国語。

## 🆘 うまく動かないとき

| 症状 | 対処 |
|---|---|
| ウィンドウが開かない | `%APPDATA%\PS HELP\startup-error.log` を確認してください |
| 「権限がありません」 | その変更には管理者権限が必要です |
| コマンドが長くかかる | 下部のコンソールで **コマンドを中止** をクリックしてください |
| 設定をやり直したい | `%APPDATA%\PS HELP\settings.json` を削除してください |
| ウイルス対策や SmartScreen が `PS HELP.exe` を警告する | このファイルには有料のデジタル署名がありません。プログラムのコードはすべて `app` フォルダーに公開されています |

## 🔒 安全ですか？

### PS HELP は Windows PowerShell の標準コマンドだけを使います。

ping やファイルのダウンロードなど、ご自身が指示したもの以外はインターネットへ何も送信しません。変更のたびに完全なコマンドを表示し、**はい** を待ちます。プログラムのコードはすべて `app` フォルダーに公開されており、読むことができます。
