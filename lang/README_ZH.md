## 💡 这是什么？

### PS HELP 把 PowerShell 命令变成一个普通窗口，里面是列表和按钮。

你不用记命令，也不用在黑色控制台里敲。你点左边的板块，点列表里的一项，再点带动作的按钮。每个按钮都会执行一条**真正的 PowerShell 命令**，而程序始终在下方显示具体是哪一条，所以你顺便就学会了 PowerShell。

一切都在一个窗口里完成：没有弹窗，背后也没有黑色控制台。程序不向互联网发送任何内容，设置留在你自己的电脑上。

## 🚀 快速上手

**1.** 从 [Releases](https://github.com/MRGREGOR85/PS-HELP-/releases/latest) **下载**压缩包，解压到任意位置，例如桌面。  
**2.** 双击**运行** `PS HELP.exe`。不会出现黑色控制台，程序把它藏起来了。首次运行时 Windows 可能通过 SmartScreen 提示：**更多信息 → 仍要运行**。  
**3.** 在左边**选择一个板块**。菜单里有十个板块，下方是**设置**。  
**4.** **点击列表中的一项**。右边会出现详情和动作按钮，**POWERSHELL 命令**框里显示该按钮将要执行的命令。  
**5.** **确认改动。** 凡是会改变什么的操作，都会先显示完整命令，并等待**是**或**否**。  
**6.** **按 F6** 进入命令模式：带 PowerShell 命令的卡片、填有示例值的输入框、**运行**、**复制**、**文档**，以及窗口下方的结果控制台。  
**7.** 在**设置**里**选择语言和皮肤**。它们会自动保存，下次启动时依然如此。  

**你需要：** Windows 10 或 11 · Windows PowerShell 5.1（每个 Windows 10/11 都自带）· 只有部分改动需要管理员权限：服务、时区、日期和脚本策略。

| 压缩包里的文件 | 作用 |
|---|---|
| `PS HELP.exe` | 整个程序只有一个文件 – 启动 PS HELP，从 U 盘也能运行 |
| `PS_HELP.ico` | 程序图标 |
| `LICENSE` | 程序许可 |

> 💡 程序文件会自动解压到隐藏文件夹 `app`。你不需要去看，也不需要改动任何东西。

## 🧭 全部板块

### ⚙️ 进程

当前正在运行的程序列表：名称、PID、带条形图的处理器占用和内存。每 2 秒自动刷新。搜索框、**刷新**、**启动程序**。点击某个程序后可以看到处理器、内存、启动时间和线程，以及**结束程序**、**打开程序文件夹**和**详情**按钮。

F6 命令： `Get-Process`, `Stop-Process`, `Start-Process`, `Wait-Process`

### 🔧 服务

Windows 服务，带状态（运行中或已停止）和启动类型。操作：**启动**、**停止**、**重启**、**自动启动**、**手动启动**、**禁用服务**。例如：打印机卡住对应的是 *Print Spooler* 服务 → **重启**。

F6 命令： `Get-Service`, `Start-Service`, `Stop-Service`, `Restart-Service`, `Set-Service`

### 📁 文件和文件夹

一个小型资源管理器：**文件夹**输入框、**向上**、**新建文件夹**、**清空回收站**。对文件可以：**打开**、**复制到…**、**移动到…**、**重命名**、**删除**（彻底删除，不进回收站）、**SHA256 校验和**，以及给从网上下载的文件**解除锁定**。

F6 命令： `Get-ChildItem`, `Copy-Item`, `Move-Item`, `Rename-Item`, `Remove-Item`, `New-Item`, `Test-Path`, `Invoke-Item`, `Get-FileHash`, `Unblock-File`, `Clear-RecycleBin`

### 🗜️ ZIP 压缩包

选中文件或文件夹，点击**压缩为 ZIP**。选中 `.zip` 文件，点击**解压 ZIP**，会解压到同名文件夹。大压缩包在后台处理，窗口不会卡住。

F6 命令： `Compress-Archive`, `Expand-Archive`

### 🌐 网络

**检查连接**会发送 4 次 ping，带响应时间和状态。**下载文件**接受用 **Ctrl+V** 粘贴的链接；窗口下方显示进度条、百分比、速度和剩余时间，随时可以用**中止下载**按钮停止。在命令模式下，`OutFile` 需要填已存在文件夹中文件的完整路径，例如 `C:\Temp\file.zip`。

F6 命令： `Test-Connection`, `Invoke-WebRequest`

### 🖥️ 计算机

计算机名、Windows 版本、处理器、核心数、内存总量和可用量、显卡、磁盘可用空间、运行时长、上次启动和更新数量。每个数值都可以复制到剪贴板。按钮：**更新列表**、**重命名计算机**、**重启**、**关机**。

F6 命令： `Get-ComputerInfo`, `Get-CimInstance`, `Get-HotFix`, `Get-Uptime`, `Get-PSDrive`, `Rename-Computer`, `Restart-Computer`, `Stop-Computer`

### 🕒 日期和时间

当前日期、时间和时区，以及可搜索的全部时区列表。**设为该时区**和**设置日期和时间**需要管理员权限。

F6 命令： `Get-Date`, `Set-Date`, `Get-TimeZone`, `Set-TimeZone`

### 📋 剪贴板

剪贴板里现在有什么，逐行显示。**复制这一行**，或者输入文字后点击**放入剪贴板**。

F6 命令： `Get-Clipboard`, `Set-Clipboard`

### 📜 事件日志

来自系统和应用程序日志的最近 200 条错误和警告：时间、级别、来源和说明。**完整说明**会显示事件的全文。

F6 命令： `Get-WinEvent`, `Get-Counter`

### 🔒 安全

各作用域的 PowerShell 脚本执行策略。对于用户作用域：**允许脚本 (RemoteSigned)**、**阻止脚本 (Restricted)**、**清除设置 (Undefined)**。**谁能访问某个文件**会以只读方式显示权限。

F6 命令： `Get-ExecutionPolicy`, `Set-ExecutionPolicy`, `Get-Acl`

## 🌍 语言

## 🆘 有东西不能用？

| 我看到的 | 怎么办 |
|---|---|
| 窗口打不开 | 检查文件 `%APPDATA%\PS HELP\startup-error.log` |
| 「权限不足」 | 该改动需要管理员权限 |
| 命令执行很久 | 在下方控制台点击**中止命令** |
| 我想把设置恢复到最初 | 删除文件 `%APPDATA%\PS HELP\settings.json` |
| 杀毒软件或 SmartScreen 提示 `PS HELP.exe` | 该文件没有付费数字签名，程序的全部代码都公开放在 `app` 文件夹里 |

## 🔒 安全吗？

### PS HELP 只使用 Windows PowerShell 自带的命令。

除了你自己要求的事情，例如一次 ping 或一次下载，它不向互联网发送任何数据。每次改动都会显示完整命令并等待**是**。程序的全部代码都公开放在 `app` 文件夹里，你可以自己阅读。
